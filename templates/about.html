Project Overview

About the Smart Event Management System

An automated web application engineered for college campus event coordination.

Project Objectives

In traditional college environments, event notices are posted on physical notice boards or fragmented WhatsApp groups, while student registrations rely on manual paper lists or scattered Google Forms.

  • Provide a centralized catalog for all departmental and collegiate events.
  • Allow students to discover event details, schedules, and coordinators in real time.
  • Enable one-click event registration while automatically blocking duplicate entries.
  • Empower administrators to manage events and export student registration rosters effortlessly.

Academic Scope & Significance

This mini project is specifically designed for TYBSc Computer Science students. It highlights practical full-stack development skills:

  • Backend Architecture: Modular Python Flask routing with session management and password hashing.
  • Relational Storage: SQLite database schema with foreign keys, constraints, and cascade management.
  • Responsive UI: Bootstrap 5 grid layout ensuring complete mobile and desktop adaptability.
  • Security: Werkzeug hashing and role-based route decorators preventing unauthorized administrative access.
